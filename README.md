# TypeScript 系统学习：Node.js 开发者路线

这是一套为“熟悉 Node.js 后端、了解前端但实践较少”的开发者设计的动手教程。目标不是背语法，而是建立三个能力：用类型表达业务约束、正确处理不可信输入、能独立配置和迁移真实 Node.js 项目。

## 开始

需要 Node.js 22.18+（可直接运行可擦除的 TypeScript 语法）。

```bash
npm install
npm run typecheck
npm run demo:all
```

也可以逐章运行，例如 `npm run demo:03`。每个源码文件顶部都有学习目标，结尾都有练习；建议先预测输出，再运行，然后完成练习并执行 `npm run typecheck`。

## 学习原则

1. 先让 TypeScript 推断，只在函数边界、公共 API 和需要约束的位置写类型。
2. 禁止用 `any` 消音；外部数据从 `unknown` 开始，通过校验进入可信域。
3. 优先使用可辨识联合表达状态，不用一组互相矛盾的布尔值。
4. 泛型用于“关联输入与输出”，不是为了让类型看起来高级。
5. `tsc` 保证的是静态一致性，运行时校验、测试和错误处理仍不可少。
